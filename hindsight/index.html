Hindsight

A pull request reviewer for Windows, powered by Claude, that learns from your team's past mistakes. Every bug that slips through becomes a rule it checks on every review that follows.

How it works

  1. Review a pull requestChoose a GitHub repository and a pull request. Claude reads the changes and reports concrete defects, each with the file, the line and a suggested fix.
  2. Teach it when something slips throughDescribe the bug or point to the pull request involved. Claude works out the root cause and proposes a prevention rule, which you edit and save as a lesson.
  3. It remembersSaved lessons are applied to every later review of that repository, and findings that break one are labelled with it.
  4. Share lessons with your teamExport them as a file and commit it to the repository. Everyone reviewing with Hindsight picks them up.

How it is built

  • Powered by ClaudeReviews and root-cause analysis are done by Anthropic's Claude models, using your own API key.
  • You stay in controlYou read every review before anything is posted. Hindsight comments on a pull request only when you tell it to, and never approves or blocks one for you.
  • No server of oursYour keys and lessons stay on your computer. The app talks only to GitHub and to Anthropic.
  • FreeHindsight is free to use and open source under the MIT licence. You pay Anthropic only for the reviews you run.

Availability

The first version is built and in testing. The Windows installer and the source code will be published here when it is released.
